# Pepa's Inventory System

Moderní webová aplikace pro správu inventáře, výrobků a skladového hospodářství.

## 🎯 Funkce

- 📦 **Správa výrobků** - Evidence výrobků s názvy a sériovými čísly
- 🏭 **Správa skladů** - Přehled skladů, stavů a počtů kusů
- 👥 **Správa kontaktů** - Evidence kontaktů a jejich skupin
- 📊 **Statistiky a grafy** - Vizualizace dat a trendů
- 🎨 **Moderní design** - Responzivní rozhraní s gradientovými barvami
- 🔐 **Zabezpečení** - Autentizace a autorizace uživatelů

## 🚀 Spuštění

```bash
# Instalace závislostí
pip install -r requirements.txt

# Spuštění aplikace
python run.py
```

## 🛠️ Technologie

- Flask
- Flask-AppBuilder
- SQLAlchemy
- Bootstrap s vlastním CSS
- FontAwesome ikony
